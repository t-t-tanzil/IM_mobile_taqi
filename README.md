# Senior App Developer Technical Assessment

This repository contains two completed mobile assignments:

- [`android-attendance/`](./android-attendance/) — Native Android attendance application built with Kotlin and Jetpack Compose.
- [`Flutter_cam_task/`](./Flutter_cam_task/) — Flutter camera, batch capture, persistent upload queue, offline handling, retry, and background synchronization application.

Each project includes its own README with setup instructions, implementation details, screenshots, testing notes, and architectural decisions.
